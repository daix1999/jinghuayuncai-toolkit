# 京华云采获取经销商联系方式

一个 WorkBuddy 技能，用于获取[京华云采](https://mkt-bjzc.zhongcy.com)（北京市政府采购平台）上经销商的联系方式。

> 两大能力：**名单补电话** + **查经销商**

## 它能做什么

### 能力一：名单补电话（反向匹配）

你手上有一张京华云采供应商名单（Excel），其中部分"联系电话"是空的。技能会：

1. 走官网接口，遍历各品类商品的经销商列表，直接拿到经销商的销售电话
2. API 查不到的，通过黄页、企查查、天眼查、政府采购网等公开渠道搜索补漏
3. 每个电话标注来源（官网 API / 公开搜索），并备注可能的法人/对接人/注册资本
4. 输出 `原名_已填充.xlsx` 副本，绝不覆盖原始文件

### 能力二：查经销商（正向维度）

按 **产品 / 品类 / 品牌**，爬取京华云采上对应的所有经销商及联系方式，统一输出格式：

| 品类 | 品牌 | 产品 | 经销商名称 | 销售电话 |
|------|------|------|-----------|---------|

支持三种维度任意组合：

- 按品类：台式机 / 笔记本 / 服务器 / 打印机
- 按品牌：联想、华为、宏碁……
- 按产品：开天M70d、X5z……

## 为什么有用

京华云采经销商数据分散在各品类的各款商品下，人工逐个点开效率极低。本技能通过抓包逆向出的 API 端点（`querySkuAgentListFromEs`），**直接返回经销商的 `agentPhone`**，无需登录、无需点击弹窗，批量获取。

## 安装

### 方式一：手动解压（推荐）

1. 下载本仓库，把 `jinghuayuncai-dealer-contact` 文件夹放进用户技能目录：

   | 系统 | 目录 |
   |------|------|
   | Windows | `C:\Users\<用户名>\.workbuddy\skills\` |
   | macOS / Linux | `~/.workbuddy/skills/` |

2. 重启 WorkBuddy（或新建会话），技能即生效

### 方式二：技能市场

通过 WorkBuddy 技能市场/推荐市场搜索安装。

## 使用

安装后，直接对 WorkBuddy 说：

- "帮我把这张京华云采名单里电话为空的补一下"
- "查一下京华云采上联想所有产品的经销商"
- "台式机品类下都有哪些经销商"
- "开天M70d 这款产品有哪些经销商在卖"

## 依赖

Python 3 + `requests` `openpyxl` `pandas`：

```bash
pip install requests openpyxl pandas
```
