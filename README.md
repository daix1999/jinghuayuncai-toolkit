# 京华云采工具包

一个 WorkBuddy 技能，用于获取[京华云采](https://mkt-bjzc.zhongcy.com)（北京市政府采购平台）上的经销商联系方式与销售成交数据。

> 三大能力：**名单补电话** + **查经销商** + **销售成交记录**

## 它能做什么

### 能力一：名单补电话（反向匹配）

你手上有一张京华云采供应商名单（Excel），其中部分"联系电话"是空的。技能会：

1. 走官网接口，遍历各品类商品的经销商列表，直接拿到经销商的销售电话
2. API 查不到的，优先用风鸟（riskbird.com）批量查询，再通过黄页、企查查、天眼查、政府采购网等公开渠道搜索补漏
3. 每个电话标注来源（官网 API / 公开搜索），并备注可能的法人/对接人/注册资本
4. 输出 `原名_已填充.xlsx` 副本，绝不覆盖原始文件

### 能力二：查经销商（正向维度）

按 **产品 / 品类 / 品牌**，爬取京华云采上对应的所有经销商及联系方式，统一输出格式：

| 品类 | 品牌 | 产品 | 经销商名称 | 销售电话 |
|------|------|------|-----------|---------|

支持三种维度任意组合：

- 按品类：台式机 / 笔记本 / 服务器 / 打印机
- 按品牌：联想、华为、宏碁……
- 按产品：开天M70d、X5z……

### 能力三：销售成交记录（成交分析）

按 **型号 / 品牌 / 品类**，拉取历史销售成交数据，统一输出格式：

| 品类 | 品牌 | 型号 | 采购单位 | 采购数量 | 采购单价(元) | 供应商 | 成交时间 |
|------|------|------|---------|---------|-------------|--------|---------|

可以看清某款机型真实卖给了谁、多少台、什么价、哪家供货——用于竞品分析、报价卡位、反向锁定供货渠道。

## 实际效果示例

**补电话**——跑完后脚本直接打印完整摘要，一眼看清结果：

```
============================================
填充结果摘要：
  名单有效数据行：100 行
  其中电话为空：34 行
  ✅ 已填充电话：23 家
  🟠 未找到电话：2 家
  ⚠️ 未匹配(映射缺失)：9 家
  ➖ 已有电话跳过：66 家
============================================
```

输出的 Excel 里，每家的电话都带来源标注（绿色=官网 API、黄色=公开搜索、橙色=未找到），还附「可能联系人及身份」列（法人/注册资本）。

**销售记录**——以联想开天 M70d 为例，拉出真实成交：

| 型号 | 采购单位 | 数量 | 单价 | 供应商 |
|------|---------|------|------|--------|
| M70d D001 (8G) | 怀柔庙城镇社区卫生服务中心 | 1 | 4448 | 阳光春雨科技 |
| M70d D001 (8G) | 海淀区国资委 | 3 | 4400 | 瑞雪正采科技 |
| M70d D001 (8G) | 门头沟农业农村局 | 14 | 4448 | 纳宇利致科技 |

从成交价（4400-4448 元）能卡准报价位，从供应商能反向锁定"正在给政府供同价位段货"的渠道。

## 为什么有用

京华云采经销商数据分散在各品类的各款商品下，人工逐个点开效率极低。本技能通过抓包逆向出的 API 端点，**直接返回经销商的 `agentPhone` 和成交记录**，无需登录、无需点击弹窗，批量获取：

- 经销商查询：`querySkuAgentListFromEs`（直接返回 agentPhone）
- 销售记录：`querySkuSaleRecord`（返回采购单位/数量/单价/供应商/时间）

## 安装

### 方式一：手动解压（推荐）

1. 下载本仓库，把 `jinghuayuncai-toolkit` 文件夹放进用户技能目录：

   | 系统 | 目录 |
   |------|------|
   | Windows | `C:\Users\<用户名>\.workbuddy\skills\` |
   | macOS / Linux | `~/.workbuddy/skills/` |

2. 重启 WorkBuddy（或新建会话），技能即生效

### 方式二：技能市场

通过 WorkBuddy 技能市场/推荐市场搜索安装。

## 使用

安装后，直接对 WorkBuddy 说：

- "帮我把这张京华云采名单里电话为空的补一下"
- "查一下京华云采上联想所有产品的经销商"
- "台式机品类下都有哪些经销商"
- "开天M70d 这款产品有哪些经销商在卖"
- "查一下开天M70d 的销售记录"

## 依赖

Python 3 + `requests` `openpyxl` `pandas`：

```bash
pip install requests openpyxl pandas
```
