# 公开信息搜索渠道与技巧

京华云采 API 查询未匹配到的供应商，按以下顺序公开搜索，命中率从高到低排列。

## 搜索渠道优先级

### 0. 风鸟批量查询（未命中公司多时首选）
- 配合 `riskbird-cominfo-batch` 技能，用 CDP 浏览器自动化批量查全国企业信息
- 数据源 riskbird.com 免费版，无需付费、无需 API Key
- 搜索结果页即可提取**电话/邮箱/地址/法人/注册资本**，不消耗额度；只有查社保参保人数才进详情页（每日 50 次额度）
- 前置条件：用户 Chrome 已打开风鸟网站 + CDP Proxy 运行（localhost:3456）+ 名单 JSON 数组
- 适用场景：一次要补几十家电话（比逐家 WebSearch 快得多）
- 注意：curl 必须加 `--noproxy '*'`（用户系统有代理，否则超时）

### 1. 黄页类网站（命中率高、号码完整）
- 云黄页 yunhuangye.com、黄页网 huangyewang.net、利酷搜 likuso.com、顺企网 11467.com、12580.tv
- 特征：直接显示"联系人 + 手机 + 座机"，无需登录
- 搜索词：`"公司全名" 电话`

### 2. 企业征信平台（权威、有时号码打码）
- 企查查 qcc.com、天眼查 tianyancha.com、启信宝 qixin.com、爱企查 aiqicha.baidu.com
- 特征：号码可能显示为 `138****1234` 打码，但能确认法人和注册资本
- 打码时可结合黄页结果拼出完整号码（前3+后4位对得上即可确认）

### 3. 政府采购网（能拿到真实对接人）
- 中央政府采购网 zycg.gov.cn、各地方公共资源交易平台、政采云 zcy.gov.cn
- 特征：中标公告/验收单里常带"成交供应商联系人 + 电话"
- 搜索词：`"公司全名" 中标 OR 成交 OR 供应商`
- 这类号码质量最高——是实际负责招投标的对接人

### 4. 公司官网
- 官网"联系我们"页面通常有座机 + 邮箱
- 搜索词：`公司全名 官网`

## 搜索词模板

```
"公司全名" 电话 联系方式
"公司全名" 联系电话
"公司全名" 中标 OR 成交 供应商
"公司全名" site:qcc.com OR site:tianyancha.com
```

## 提取联系人身份的技巧

搜索结果中常见的关键人物信息：
- **法定代表人**：天眼查/企查查的"法定代表人"字段
- **实际对接人**：政府采购公告的"成交供应商联系人"
- **股东/实控人**：年报中的股东信息
- 身份备注格式：`法人:XXX, 注册资本XXX万, 主营XXX`

## 注意事项

1. **同名不同公司**：北京同名的公司很多（如"宇鑫科技"有多个），务必核对统一社会信用代码或注册地址
2. **号码打码**：征信平台号码常打码，用黄页/政府采购结果交叉验证
3. **已更名/注销**：搜索到"曾用名"或"注销"状态时，备注清楚，避免打错公司
4. **座机 vs 手机**：优先保留手机号（座机可能换人），多个号码用" / "分隔
5. **无法确认的号码**：宁可标注"未找到"，不要填猜测的号码——错号比空号更伤信任
